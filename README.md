# Light ON/OFF React App

## Run the project
1. Extract this ZIP.
2. Open the extracted `light-on-off-react` folder in VS Code.
3. Open a terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

Click **ON/OFF** to toggle the bulb between switched ON (yellow glow) and switched OFF.

## Important
Run `npm install` from the same folder that contains `package.json`.
